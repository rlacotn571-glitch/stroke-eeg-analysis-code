# Artifact correction and agreement across repeated recordings in lower-limb motor imagery EEG after stroke

Analysis code for the study by Chaesu Kim. The main comparison asks how the direction of an individual's change in central beta power varies when the artifact-correction threshold changes for fixed recordings, and when different recordings represent the same visit under a fixed threshold.

## Rebuild the paper tables and figures

Use Python 3.12. The analysis environment is recorded in [requirements-lock.txt](raw_processing/outputs/stroke_analysis_full/requirements-lock.txt). From the repository root, install the dependencies in a fresh environment.

~~~sh
python -m pip install -r raw_processing/outputs/stroke_analysis_full/requirements-lock.txt
~~~

The rebuild reads numerical inputs supplied separately in the study's supplementary archive, **Reproducibility.zip**. In a working copy of the repository, extract the archive's CSV and NPZ files with their relative paths intact. For example, the extracted files should include `identity/recording_fingerprints.csv` and `outputs/stroke_analysis_full/trial_metrics_all_stages.csv`. From that working copy, run:

~~~sh
python rebuild.py
~~~

Table 3 is written to `tables/within_visit_comparisons.csv`. The final Figure 5 is generated by `matched_figure.py`. Its source values include `outputs/BSPC/run_splits/participant_splits.csv`. The rebuild also produces the other main figures and supplementary figures S1, S4 and S5, and reports S3 and S6. The illustrated S2 atlas requires recording-specific fits and is supplied separately.

## Follow the analysis from the public EEG

The original processing scripts are archived under `raw_processing/`. The raw recordings, per-recording fits and numerical analysis files are external inputs. To repeat the stroke preprocessing, use a separate working copy of `raw_processing/` as the project root, preserving its `outputs/` directory.

1. Place the pinned [NEMAR stroke dataset nm000270 v1.0.6](https://ww2.nemar.org/dataset/nm000270?v=v1.0.6) in `outputs/EEG_datasets/nm000270_v1.0.6/`. Include the BrainVision files and event tables under `sourcedata/`. Save the [versioned download manifest](https://data.nemar.org/nm000270/v1.0.6/manifest.json) in the dataset directory as `full_remote_manifest.json` for file validation.
2. Run `python outputs/stroke_analysis_full/run_full.py` from this raw-processing root. The script enumerates the pre, post and follow-up recordings, fits ICA, applies the reference and ICLabel rules, and validates each recording.
3. Run `python outputs/stroke_analysis_full/summarize_full.py` after all per-recording validations complete. It writes the trial metrics and other summaries used downstream. These early summaries precede the recording-identity checks. The paper's inclusion masks and final comparisons are implemented in `population.py`, `main_results.py` and the analysis directories under the repository's top-level `outputs/BSPC/`.
4. For the independent physical-phantom analysis, place [NEMAR on004784 v1.0.0](https://nemar.org/dataset/on004784) in `outputs/EEG_datasets/on004784_v1.0.0/`. Include the six SET/FDT pairs and the ground-truth MAT file under `stimuli/`. Run `python outputs/phantom_validation/benchmark.py` from the raw-processing root.

Other upstream scripts document individual checks and expect the original project layout, intermediate files and recording-specific fits. For example, the source-identity check uses the [original Figshare deposit](https://doi.org/10.6084/m9.figshare.27130299.v1). For the paper's final participant exclusions and uncertainty estimates, use the rebuild above with the audited numerical inputs.

## Key scripts

| Scientific question | Code |
| --- | --- |
| Which recordings contribute to each comparison? | `population.py`, `main_results.py` |
| How does changing the threshold affect a fixed set of recordings? | `outputs/BSPC/sensitivity/` and `outputs/BSPC/run_splits/analyze.py` |
| How does changing the recordings affect the same participant's visit estimate? | `outputs/BSPC/run_splits/analyze.py`, `outputs/BSPC/split_attribution/analyze.py` |
| Where are the paired comparisons displayed together? | `matched_figure.py` |
| How was recovery measured against the phantom's known input? | `raw_processing/outputs/phantom_validation/benchmark.py` |
